# macOS-Einstellungen für jkkonfig, eine Zeile pro Wert.
#
#   gruppe | domain | schlüssel | typ | wert bei »ein« | wert bei »aus« | modus
#
# gruppe:   arbeitsplatz  gehört zu »jkkonfig ein/aus« und wird bei »aus« zurückgenommen
#           komfort       persönliche Systemeinstellungen, »aus« lässt sie unberührt
#           anim          Animationen, umgeschaltet mit »jkkonfig anim ein/aus«
# typ:      bool, int, float oder string
# wert:     ein Wert, »-« löscht den Schlüssel (Systemvorgabe gilt), »=« lässt ihn unberührt
# modus:    a  immer
#           i  nur bei ausdrücklichem Aufruf (die Domain gehört einer sandboxed App
#              und kann eine Berechtigungsabfrage auslösen, nie in der Wartung)
#           d  hängt vom Dock-Zustand ab, wird gesondert behandelt
